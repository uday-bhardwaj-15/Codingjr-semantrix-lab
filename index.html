About CodingJr Semantic Labs

How It Works

CodingJr Semantic Labs lets you train your vocabulary and associative thinking using real-time Natural Language Processing and dictionary semantics.

🎮 Arcade Mode

Type clues that are semantically connected to the target words. The AI evaluates semantic proximity and scores your match before the stack hits the danger line!

🧩 Blocks Mode

Take your time to find words matching color clusters. Solve the puzzle by grouping and clearing connected blocks.

🤖 Automated Solver API

Developers and students can connect automated Python models to solve games via Selenium or the built-in window.game.currentGame JS interface.
